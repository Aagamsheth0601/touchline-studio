## Updating the library

Migration 004 stores source title, URL and checked date beside each note. It clears changed embeddings so the existing privileged indexing operation rebuilds vectors from the revised title and content. Source metadata travels with the retrieval result but is not added to the embedding text. The browser only renders HTTPS links to the reviewed publisher.

No full articles, illustrations or videos are stored. Source material retains its original ownership. Coach review remains a future opportunity, not a completed milestone.

## Retrieval check

The ten-case smoke evaluation checks eight relevant questions (one expected note per topic), two unrelated questions, attribution, and denied public access to indexing/table reads. All passed on 2026-10-13. Intended notes appeared in the first three for 8/8 relevant cases and ranked first for 6/8. Both unrelated queries were filtered out at 0.82.

This is a tiny development set, not a general accuracy benchmark. Similarity does not establish correctness or source support. A broader held-out set and human review are needed before making quality claims. Search still returns notes, not generated answers.
